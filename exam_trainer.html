    Everything the four calculation questions need, plus the update rules she asks you to distinguish. Nothing here needs a calculator.

    The one update rule

    Everything is this shape
    New ← Old + α [ Target − Old ]
    Only the bootstrap term changes
    Q-learning target = r + γ·maxa′ Q(s′,a′) SARSA target = r + γ·Q(s′,a′) ← the GIVEN a′ Exp. SARSA target = r + γ·Σ π(a′|s′)Q(s′,a′) TD(0) target = r + γ·V(s′) MC target = Gt
    The single most common slip: using max for SARSA, or the given a′ for Q-learning. Read the algorithm name first, then circle the bootstrap value in the table before you compute anything.

    Q-learning / SARSA recipe

    1. Write down the old value Q(s,a) from the table.
    2. Find the bootstrap value in the next state's row: max for Q-learning, the given a′ for SARSA.
    3. Target = r + γ · (bootstrap).
    4. TD error = target − old.
    5. New = old + α · (TD error).
    Worked: state 2 → Left → state 1, r = 2, α = 0.5, γ = 0.9, Q(2,Left) = 4, row of state 1 = (5, 2, 1, 4)
    Q-learning: 4 + 0.5[2 + 0.9·5 − 4] = 4 + 0.5(2.5) = 5.25 SARSA (a′=Right, Q=4): 4 + 0.5[2 + 0.9·4 − 4] = 4.80

    UCB and UCT

    Bandit UCB — counts over time
    At = argmaxa [ Qt(a) + c·√( ln t / Nt(a) ) ]
    UCT — counts at a tree node
    a* = argmaxa [ Q(s,a) + c·√( ln N(s) / N(s,a) ) ]
    Q(s,a) in UCT is already the MEAN return
    Do not divide by N(s,a) again — unless the column is labelled "total" or "sum of returns", in which case compute Q = W / N first.
    Square roots worth memorising
    √0.25=0.5 √0.4≈0.63 √0.5≈0.71 √0.67≈0.82 √1.33≈1.15 √2≈1.41 √3≈1.73 √4=2

    PPO clipping

    Objective
    L = min( rt·Ât , clip(rt, 1−ε, 1+ε)·Ât )
    Worked: r = 2, Â = 5, clip [0.8, 1.2]
    min( 2·5 , 1.2·5 ) = min(10, 6) = 6
    Sign check: r = 2, Â = −5
    min( −10 , −6 ) = −10 — not clipped!
    The clip only bites when…
    Â > 0 and r > 1+ε (already pushed up a lot) Â < 0 and r < 1−ε (already pushed down a lot)

    Returns, advantages, traces

    Return
    Gt = Rt+1 + γRt+2 + γ²Rt+3 + … constant reward r forever → G = r/(1−γ)
    n-step return
    Gt(n) = Σk<n γkRt+k+1 + γnV(St+n)
    λ-return
    Gλ = (1−λ) Σn λn−1 G(n) (λ=0 → TD, λ=1 → MC)
    TD error and GAE
    δt = Rt+1 + γV(St+1) − V(St) Ât = Σl≥0 (γλ)l δt+l

    RUDDER redistribution

    Rule
    r̃t+1 = Ĝt+1 − Ĝt
    Worked: Ĝt+1 = 4, Ĝt+2 = 10
    change at t+2 = 10 − 4 = +6 → t+2 gets more credit
    The idea in one line
    Credit goes where the return prediction changes most, not where it is largest.

    Deep value-based bits

    Double DQN target
    y = r + γ Qw⁻( s′ , argmaxa′ Qw(s′,a′) )
    Dueling head
    Q(s,a) = V(s) + A(s,a) − (1/|A|) Σa′ A(s,a′)
    Prioritized replay
    P(i) = piα / Σ pkα, pi = |δi| + ε IS weight wi = ( 1 / (N·P(i)) )β, β: 0 → 1
    Importance ratio
    ρt = π(At|St) / µ(At|St)

    Data-centric and LLM bits

    BC vs DAgger bounds
    BC: expert error + T²·ε DAgger: expert error + T·ε
    Model-based rollout error
    total error ≤ H · ε (linear in the horizon)
    Ensemble variance split
    Var = (1/M)ΣΣφi ← aleatoric + (1/M)Σ(µφi − µ̄)² ← epistemic
    Bradley–Terry
    P(τw ≻ τl) = σ( r(τw) − r(τl) )
    GRPO advantage
    Âi = ( ri − mean(r1:G) ) / ( std(r1:G) + δ )
    Dyna-Q+ bonus
